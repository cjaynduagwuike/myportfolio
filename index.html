Signal Ranking Model

The Problem

Reviewers of search signals need to prioritize which signals to fix first, but the current process is manual and time-consuming. A model that can rank signals by their likelihood of improving search visibility would allow reviewers to focus on the most impactful fixes.

Stack

Python, Pandas, Scikit-learn, XGBoost, Flask, Docker, AWS S3, AWS Lambda

Result

The model is able to rank signals by their likelihood of improving search visibility, allowing reviewers to prioritize fixes that will have the greatest impact.

Status

Currently in production, with a live dashboard for reviewers to see the model's recommendations and track their impact on search visibility.
